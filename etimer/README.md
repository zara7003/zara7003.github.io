# Voice & Visual Workout Interval Timer (Smart TV Optimized)

Hosted on GitHub Pages (`sahilshaikh.org/etimer`).

## Features & Settings
- **Smart TV Remote Optimized**: Default focus (`autofocus`) on the **Start** button so you only need to press **OK / Enter** on your remote to start instantly.
- **Voice Cues (Speech) Setting**: Configurable in **⚙️ Settings** (Yes / No, enabled by default) allowing you to switch between full voice announcements and pure chime beeps.
- **Background Radio On/Off**: Fully toggle background music on or off.
- **Radio Channel Switcher**: Choose from multiple live stations (Upbeat Fitness, Synthwave Energy, Chill Lo-Fi / Groove Salad).
- **Radio Play Time (On/Off Scheduling)**: Choose whether music plays continuously ("Play Always"), "During Work Intervals Only", or "During Breaks Only".
- **Web Audio Chimes**: Robust synthesized audio tones ensuring clear audio feedback even on TV browsers that restrict speech synthesis.
- **Fully Customizable**: Adjust prep time, work time, set breaks, exercise breaks, and customize all exercise names directly from the on-screen settings panel.

## Deployment
Simply upload `index.html` to your GitHub repository and enable GitHub Pages.
